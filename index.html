Everything Nexora AI Does

Built from the ground up to make your browser fast, intelligent, and secure.

🎵

YouTube & Tab Control

Open YouTube, search for music, group tabs by category (*Study, Work, Social, Media*), close duplicate tabs instantly, and mute/unmute active tabs.

🎙️

Voice Copilot & AI Q&A

Push-to-talk voice commands (Web Speech API). Ask general questions like *"Who is Sam Altman?"* or *"Who is Satya Nadella?"* and receive Google & Gemini 2.0 answers.

📄

Executive Page Summarizer

Extracts active browser DOM text and synthesizes Executive Overviews, Key Analytical Takeaways, Core Topics, and Target Audience without raw text copying.

💬

WhatsApp Web Integration

Reads incoming WhatsApp Web messages, drafts context-aware replies across 5 tones (*Hinglish, Friendly, Professional*), and types into composer **without auto-sending**.

🛡️

Fake News & Scam Analysis

Analyzes incoming messages for high-urgency language, phishing patterns, unverified reward claims, and OTP/password requests with confidence scores.

⏱️

Pomodoro Focus Session

25-minute Pomodoro focus timer backed by `chrome.alarms` and `chrome.storage.local` that survives sidepanel closures with session tab analytics.

How to Install in 3 Easy Steps

Load Nexora AI in Google Chrome Developer Mode

1

Build Package

Run npm run build:extension in terminal to create the distribution package.

2

Load Unpacked

Open chrome://extensions, turn on Developer mode, and click Load unpacked.

3

Select Dist Folder

Select extension/dist folder. Pin Nexora to open the Side Panel!
